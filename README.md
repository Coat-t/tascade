# Tascade

Cool speedrunning mod for Minecraft 1.16.1 Fabric.

Race against an opponent in a singleplayer world just like in mcsrranked, play solo mode, or create a custom room to have fun with your friends!

## Not for speedrun.com

Tascade is purely for fun and practice. It is **not** a legal mod for runs submitted to speedrun.com, and it never will be. To keep runs fair and fun, it changes loot tables, piglin barters, mob spawns etc. Don't use it for runs you plan to submit.

## Requirements

- Minecraft 1.16.1
- [Fabric Loader](https://fabricmc.net/) 0.19.3 or newer
- [SpeedrunAPI](https://github.com/Minecraft-Java-Edition-Speedrunning/legal-mods) 2.0 or newer
- [SpeedRunIGT](https://modrinth.com/mod/speedrunigt) 14.1 or newer

## Developing Tascade

IntelliJ IDEA Community Edition is the recommended IDE for writing code in java.

Download the source code:
```sh
git clone https://github.com/Coat-t/tascade.git
cd tascade
```

Update to the latest commit:
```sh
git pull
```

## Build the mod
```sh
./gradlew build
```

The mod jar is written to `build/libs/`.
